Stuck?  Git specifics ▼
What do I do when I get a merge conflict?
Git will mark the conflicting file with <<<<<<< HEAD and ======= and >>>>>>> sections. Open the file, decide which version is correct (or combine them manually), delete the marker lines, save the file, then run git add . and git commit. VS Code has a built-in merge editor — use it.
I committed something I shouldn't have
If you haven't pushed yet: git reset --soft HEAD~1 undoes the last commit but keeps your changes. If you have pushed: don't panic. Ask Claude Code to walk you through a revert — the exact command depends on the situation.
What should a commit message say?
Format: type: short description. Types: feat (new feature), fix (bug fix), refactor (restructuring), docs (readme changes). Example: feat: add player_take_damage function. Future you will thank present you.
