Environment Setup — Windows

1
Install Visual Studio Community (free)
Go to visualstudio.microsoft.com. During install, select the workload "Desktop development with C++" — nothing else required. This gives you a compiler (MSVC), a debugger, and an IDE. Install takes ~10–20 mins.
2
Install VS Code (your day-to-day editor)
code.visualstudio.com → install. Then open VS Code, go to Extensions (Ctrl+Shift+X), install C/C++ by Microsoft and C/C++ Extension Pack. VS Code is where you'll write code. Visual Studio is just the compiler we're borrowing.
3
Verify your compiler works
Open the Developer Command Prompt for VS (search it in Start menu). Type cl and hit Enter. If you see version info — you're good. If "not recognized" — re-run the Visual Studio installer and confirm C++ workload is checked.
4
Install Git
git-scm.com → download and install. Accept all defaults. After install, open a new terminal and run git --version to confirm. Then run:
git config --global user.name "Your Name"
git config --global user.email "you@email.com"
5
Create a GitHub account and your first repo
Go to github.com → sign up. Create a new repo called game-dev-exercises, set it to Private. This is where every exercise in this roadmap gets committed.
6
Install Claude Code
This is your AI coding partner. Install it at claude.ai/code. You'll use it for acceleration — not for thinking. Phase 7 covers exactly how to use it properly at each stage.
