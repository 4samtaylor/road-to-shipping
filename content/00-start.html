Environment Setup — Windows

1
Install Visual Studio Community (free)
Go to visualstudio.microsoft.com. During install, select the workload "Desktop development with C++" — nothing else required. This gives you a compiler (MSVC), a debugger, and an IDE. Install takes ~10–20 mins.
2
Install VS Code (your day-to-day editor)
code.visualstudio.com → install. Then open VS Code, go to Extensions (Ctrl+Shift+X), install C/C++ by Microsoft and C/C++ Extension Pack. VS Code is where you'll write code. Visual Studio is just the compiler we're borrowing.
3
Verify your compiler works
Open the Developer Command Prompt for VS (search it in Start menu). Type cl and hit Enter. If you see version info — you're good. If "not recognized" — re-run the Visual Studio installer and confirm C++ workload is checked.
4
Install Git
git-scm.com → download and install. Accept all defaults. After install, open a new terminal and run git --version to confirm. Then run:
git config --global user.name "Your Name"
git config --global user.email "you@email.com"
5
Create a GitHub account and your first repo
Go to github.com → sign up. Create a new repo called game-dev-exercises, set it to Private. This is where every exercise in this roadmap gets committed.
6
Install Claude Code
This is your AI coding partner. Install it at claude.ai/code. You'll use it for acceleration — not for thinking. Phase 7 covers exactly how to use it properly at each stage.
7
First launch: open your exercises folder, not a file
Clone your repo once: open a terminal, cd C:\Users\4samt\Documents\Dev, then git clone https://github.com/4samtaylor/game-dev-exercises.git.

In VS Code: File → Open Folder… → pick game-dev-exercises → click Yes, I trust the authors. Always open the whole folder. Opening a single .c file gives you no terminal in the right place, no Git, and no search across files.

The layout, left to right:
Activity bar (thin icon strip on the far left): Explorer (files), Search, Source Control (Git), Run & Debug, Extensions.
Side bar: whatever the icon you clicked shows. Explorer is the one you'll live in.
Editor: your open files, as tabs. Drag a tab to the side to see two files at once.
Panel (bottom): the Terminal and the Problems list. Toggle it with Ctrl+`.
Status bar (very bottom): current Git branch, errors and warnings count, line and column.
8
Make VS Code's terminal able to compile
cl only works in a terminal that has run Visual Studio's setup script. Out of the box, VS Code's terminal hasn't, which is why you get 'cl' is not recognized. Fix it once:

Press Ctrl+Shift+P, type Open User Settings (JSON), press Enter, and paste this inside the outer { }. If the file already has settings in it, add a comma after the last one first.
settings.json 
"terminal.integrated.profiles.windows": {
    "Developer Command Prompt": {
        "path": "cmd.exe",
        "args": ["/k", "C:\\Program Files\\Microsoft Visual Studio\\2022\\Community\\VC\\Auxiliary\\Build\\vcvars32.bat"]
    }
},
"terminal.integrated.defaultProfile.windows": "Developer Command Prompt"
Save, then open a new terminal with Ctrl+Shift+`. You should see a Visual Studio Developer Command Prompt banner. Type cl: version info means it worked.
Still not found? Open C:\Program Files\Microsoft Visual Studio in File Explorer and check the folder names. If yours says 18 or 2026 instead of 2022, change that part of the path. Backslashes in JSON have to be doubled, like above.
9
How every session starts
Same five moves every time, so starting takes no thought:
1. Open VS Code. It reopens your folder where you left it.
2. Ctrl+` for the terminal, then git pull to get anything Person A pushed.
3. Open this roadmap and press Continue on the home page, or go to Weekly Practice for this week's exercises.
4. Read the Learn stage before touching code. Then do the task.
5. When it works: tick the task here, then commit and push.
10
Start writing code: one folder per phase, one file per exercise
Keep the repo tidy from day one, so you can find last month's code when an exercise says "rebuild it from memory":
game-dev-exercises\
  p01\hello_world.c   build.bat
  p02\guess.c   frame_counter.c
  weekly\2026-W42_predict_escapes.c  # weekly exercises go here
  .gitignore
New folder: hover the Explorer and click the folder-plus icon. New file: click the page-plus icon, type the name with .c on the end, Enter. The file opens ready to type.
Then: type the code (don't paste starter code you haven't read), Ctrl+S to save. A white dot on the tab means unsaved, and the compiler only sees what's saved.
The terminal follows you: cd p02 before compiling a file in p02. Or right-click the folder in Explorer → Open in Integrated Terminal.
11
Compile and run
The quick version, from the folder your file is in:
cl /W4 guess.c  # compile with all the useful warnings → guess.exe
guess.exe  # run it
cl /W4 /Zi /Od guess.c  # debug build, for stepping through with the debugger
From Phase 1 on you'll use build.bat, which holds the flags so you just type build. Press ↑ in the terminal to bring back the last command: compile and run becomes two keystrokes each.

Reading an error: guess.c(14): error C2143: syntax error: missing ';' before '}' means file, line 14, error code, what's wrong. Ctrl+click the file name in the terminal to jump to that line. Fix the first error first, because one missing ; can cause ten more. Warnings (C4xxx) still produce an .exe, but treat them as bugs you haven't met yet.
12
Shortcuts worth learning first
Learn three a week. By Phase 3 you won't reach for the mouse.
Ctrl+SSave. Do it before every compile. Ctrl+`Show or hide the terminal Ctrl+PJump to any file by typing part of its name Ctrl+Shift+PCommand palette: every VS Code action, searchable Ctrl+/Comment or uncomment the line (or selection) Ctrl+DSelect the next match of the current word. Rename in a few presses. Alt+↑ / ↓Move the current line up or down Shift+Alt+↓Duplicate the current line Ctrl+GGo to a line number, straight from an error message F12Go to where a function is defined Ctrl+Z / Ctrl+YUndo / redo Ctrl+BHide the side bar for more room
In the terminal: ↑ repeats the last command, Tab finishes file names, cls clears the screen, Ctrl+C stops a program that's stuck in a loop.
