// Format specifiers
%dint
%ffloat — 6 decimals by default
%.2ffloat, exactly 2 decimals
%lfdouble (scanf only — printf uses %f)
%sstring — reads/prints until '\0'
%csingle char
boolno specifier — print as %d, gives 1/0
// Escape sequences
\nnew line
\rcursor back to line start — repaint in place
\ttab
\\literal backslash
%%literal percent sign (printf only)

// -> vs .
p.xp is a struct value
p->xp is a pointer to a struct
p->x is shorthand for (*p).x — follow the pointer, then dot.
// scanf(" %c") space rule
The space before %c eats the leftover newline sitting in the input buffer from the last Enter press. Without it, scanf reads Enter instead of your character. Doesn't apply to %d, %f, or %s — only %c.
// rand() idiom
rand() % (how many) + (lowest)
Example: rand() % 6 + 1 → 1 to 6, a die roll. Always call srand(time(NULL)) once at the top of main first.
