Weekend Sync Agenda — with Person A
~45 min
▼
Agenda Template  Run this every Sat/Sun sync, in order
1
Demo what you built this week
Run it live. Don't describe it from memory — pull it up and let Person A watch it work (or fail).
2
Show one thing that confused you, and what you learned
Pick the one bug or concept that actually cost you time. Walk through what you tried and what fixed it.
3
Ask one code-review question about their code
Find one line in Person A's code you don't fully understand and ask them to explain it. This is how you build the habit of reading real code.
4
Pair for 30 min on the next roadmap task
Work the next task together, live, instead of solo. One drives, one reads.
5
Agree next session's target
Name the specific task or checkpoint you're both aiming to hit before the next sync — not "keep going."
Person A reviewing your commits is the point of pushing to GitHub every session — not just backup.
